# Codesteps 🌟  

An inclusive learning platform designed to make programming accessible and enjoyable for individuals with dyslexia, ADHD, and other learning disabilities. Codesteps provides bite-sized, engaging content with features such as text-to-speech, animations, quizzes, and progress tracking to ensure an effective learning experience.

---


## About the Project  

**Codesteps** is crafted to help learners overcome the challenges of long, dense programming materials. By breaking down topics into small, digestible modules with text-to-speech narration, visual aids, and quizzes, we aim to enhance understanding and retention.  

### Key Objectives:  

- Simplify programming concepts with small, engaging slides.  
- Include AI-powered text-to-speech for audio narration.  
- Use animations and visual aids to clarify complex concepts.  
- Offer quizzes with immediate feedback to reinforce learning.  
- Provide gamification elements such as streaks and progress tracking.

---

## Features  

- **Topic Breakdown**: Input a programming topic (e.g., "Arrays") to generate small, concise slides.  
- **AI-Powered Text-to-Speech**: Audio narration for each slide using AI-generated voices.  
- **Visual Aids**: Short animations and figures for better understanding.  
- **Interactive Quizzes**:  
  - Fill in the blanks.  
  - Recognize text from images (MCQs).  
  - Retry option for incorrect answers.  
- **Gamification**:  
  - Streaks for continued learning.  
  - Completion tracker with a progress bar for modules.

## Technologies Used  

### Backend  

- **Flask**: To handle server-side logic and APIs.

### Frontend  

- **React**: To build an interactive and responsive user interface.  

### Others  

- **Text-to-Speech**: AI-powered conversion for slide narration.
